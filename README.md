# Wame --- Abrir WhatsApp

**Link:** https://gerson-santiago.github.io/Wame/

Uma **PWA (Progressive Web App)** simples para abrir conversas no
WhatsApp (Pessoal ou Business) sem precisar salvar o número.

Projeto desenvolvido com **TypeScript + Vite**.

------------------------------------------------------------------------

## ✨ Funcionalidades

-   Abertura do WhatsApp **Pessoal** ou **Business**\
-   **Detecção automática da plataforma** (Android/iOS) para abertura
    otimizada\
-   **Fallback automático** para `wa.me/` caso o deep link falhe\
-   Instalável como **PWA**

------------------------------------------------------------------------

## 🧪 Como Rodar Localmente

### 1. Clone o projeto e instale as dependências:

``` bash
git clone https://github.com/Gerson-Santiago/Wame.git
cd Wame
npm install
```

### 2. Rode o servidor de desenvolvimento:

``` bash
npm run dev
```

------------------------------------------------------------------------

## 🚀 Deploy (GitHub Pages)

Para atualizar o site no GitHub Pages, execute:

``` bash
npm run deploy
```

Este comando irá gerar automaticamente o **build** na pasta `dist/` e
publicar o conteúdo na branch `gh-pages`.
